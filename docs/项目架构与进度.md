### 2.2 数据流（双数据源）

```
页面 → utils/data.js ─┬─ cloud-api.js → wx.cloud.callFunction('articles')
                      │                 → 云函数 → 云数据库集合 articles
                      └─ mock-api.js  → wx.request → mock-server（内存数据）
```

- 切换只改 `utils/config.js` 的 `DATA_SOURCE`（`cloud` / `mock`），**页面代码零改动**
- 云开发为默认；mock 用于离线开发/断网演示
- 统一返回格式：`{ code, message, data }`，`code = 0` 表示成功

### 2.3 云函数 `articles`（单函数多 action）

| action | 说明 | 参数 |
|---|---|---|
| `ping` | 健康检查 | 无 |
| `list` | 列表（不含正文） | `page`、`size`、`keyword` |
| `detail` | 详情 | `id` |
| `seed` | 初始化 10 条示例（幂等，自动建集合） | 无 |

客户端封装：`utils/cloud-api.js`（`getArticles` / `getArticle` / `checkHealth` / `seed`）。
App 启动时自动调用一次 `seed`（幂等，失败静默）；「关于」页有手动按钮。

### 2.4 Mock 服务

| 接口 | 说明 |
|---|---|
| `GET /api/health` | 健康检查 |
| `GET /api/articles?page=&size=&keyword=` | 列表分页 |
| `GET /api/articles/:id` | 详情（404 处理） |

零依赖（只用 Node 内置模块），监听 `0.0.0.0:3001` 以支持真机调试；启动日志会打印当前局域网 IP。

### 2.5 游戏「星河战机」（小程序 Canvas 页面）

| 文件 | 职责 |
|---|---|
| `pages/game/game.js` | 页面状态、RAF 循环、输入、渲染、Boss/道具/碰撞调度 |
| `pages/game/logic.js` | 纯函数：碰撞、弹道、Boss 阶段、刷怪间隔（可单测） |
| `pages/game/audio.js` | WebAudio 实时合成音效（零素材，环境不支持时静音） |

机制：相对拖动（1.2px 死区）、自动开火、3 级火力、3 种敌机、每 60 秒 Boss（三阶段弹幕 + 顶部血条）、暂停/恢复 3 秒倒计时、最高分 Storage。

## 5. 已知问题与技术债

| 问题 | 说明 / 影响 | 建议 |
|---|---|---|
| 工具回写 `project.config.json` | 开着开发者工具时改 appid/settings 会被覆盖 | 改配置前先关闭工具；改完重启 |
| AppID 是「小程序」类型 | 无法作为独立小游戏运行；提审时游戏内容有类目风险 | 游戏保持页面形态，发布前隐藏入口 |
| 数据全局共享 | 云数据库只有一份 `articles`，所有用户看到相同数据 | 需要多用户时加 `_openid` 维度或只读设计 |
| 自动 seed 每次启动调用 | 幂等，但每次启动多一次云函数调用 | 可接受；如需优化可在 Storage 记录已初始化 |
| 云函数依赖 `wx-server-sdk: latest` | 每次部署拉最新，行为可能随版本变化 | 稳定后可锁定版本 |
| 游戏触控手感 | 模拟器与真机存在差异（灵敏度/帧率） | 发布前真机验证，必要时加灵敏度设置 |
| CI 不跑云端/真机 | 只验证语法、JSON、单测 | 云端验证靠 `cli` + 手机；可在 README 固化自检清单 |
| `tools/*.exe` 未入库 | 232MB 安装包被 gitignore | 新机器按 README 下载官方安装包 |
