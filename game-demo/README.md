# 星河战机（小游戏 Demo）

原创纵版射击小游戏，玩法参考经典街机纵版射击（雷霆战机 / 飞机大战 类）。
**代码与图形全部原创、零外部素材**（无图片、无音频），全部用 Canvas 2D 实时绘制。

## 玩法

- 按住屏幕左右拖动移动战机，自动开火
- 击落敌机得分：小型 10 / 中型 30 / 精英 100
- 蓝色菱形道具提升火力（最高 3 级：单发 → 双发 → 三发）
- 中弹或撞机：掉 1 点血、火力降 1 级，并获得约 1.2 秒无敌
- 血量归零游戏结束，最高分保存在本地 Storage

## 在开发者工具中运行

1. 开发者工具 → 项目 → 导入项目
2. 目录选择本文件夹 `game-demo`（`project.config.json` 里 `compileType: "game"`，会自动识别为小游戏）
3. 若提示 AppID 不可用：导入时改用「测试号」，或换成已开通小游戏的账号 AppID
4. 模拟器里即可直接玩；点「预览」扫码可上手机

## 说明

- 这是**学习用途的原创实现**，不是《雷霆战机》的复制品：
  未使用原游戏的名称、美术、音频、代码中的任何内容。
- 小游戏**发布**需要小游戏账号 + 游戏类目 + 版号（企业资质），个人主体基本不可行；
  本地开发、真机预览不受影响。
- 想调难度：修改 `game.js` 里的 `spawnEnemy`（生成速度/血量）、`update` 里的
  `base`（生成间隔）和 `player.maxHp`（血量）。
